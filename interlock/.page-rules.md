# Rules for the Interlock app page (hosted as a claude.ai Artifact)

Copied from the Artifact tool's page contract. Follow all of it.

- Author `index.html` as page content only: no `<!doctype>`, `<html>`, `<head>` or `<body>` tags (a skeleton is added at publish). Put `<title>Interlock</title>`, `<meta name="claude:viewport-fit-sides" content="cover">` and your `<style>` at the top.
- Skeleton already sets: charset + viewport meta (viewport-fit=cover), light color-scheme, :root padded top/bottom by safe-area insets (keep it), body margin 0, 14px system font, img{max-width:100%}, [hidden]{display:none!important} (toggle with el.hidden).
- External scripts ONLY from cdnjs.cloudflare.com (preferred), cdn.jsdelivr.net/npm/, unpkg.com, pinned to an exact version at least two weeks old (UMD builds). Stylesheets ONLY from fonts.googleapis.com (fonts.gstatic.com font files). Everything else is blocked silently, including fetch to other hosts. `fetch()` / `import` of files published next to the page with relative URLs works. Prefer no libraries; canvas/SVG by hand is fine.
- No alert/confirm/prompt (they do nothing), no window.print, no downloads via links, no iframes. Real `<a href>` links open in a new tab.
- localStorage only for conveniences, wrapped in try/catch.
- Must work at ~400px phone width with no horizontal page scroll. Side gutter on body or one outer wrapper: `padding-left: max(16px, env(safe-area-inset-left, 0px)); padding-right: max(16px, env(safe-area-inset-right, 0px));` with `padding-block` for vertical. Flex/grid rows wrap; children holding text/tables get `min-width:0`; only tables/charts/code may be wider, inside their own `overflow-x:auto`.
- Theme-aware, three states. Every color is a token on bare `:root` (light values). Redefine the same tokens under `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { ...; color-scheme: dark } }` AND under `:root[data-theme="dark"] { ...; color-scheme: dark }`. `body { background: var(--bg); color: var(--fg) }`. No literal colors in component rules; chart text uses tokens. (A deliberate dark-first single look is allowed: then set every color explicitly and `color-scheme: dark` on :root.)
- Complete at rest: the first frame shows a realistic working state (the replay already run / mid-run), no opacity:0 waiting for observers, no 100vh hero.
- Typography: pair a characterful display face with a body face (Google Fonts, real fallback stacks), tabular-nums for numbers, text-wrap: balance on headings. Avoid Inter / Space Grotesk, cream+terracotta serif, near-black with one acid-green pop, purple-blue gradients, emoji markers, rounded-lg on everything.
- Semantic colors (good / warning / critical) separate from the accent. Encode state in form (pill, chip, stripe), not just numbers. Charts drawn to scale with labels that name values reached.
- Visible keyboard focus; respect prefers-reduced-motion; stable `id` on every control; close every element; double-quote attributes.
- Copy: plain, active voice, the user's words (dispatcher, homes, backup, circuit). No em-dash asides, no "not X but Y", no scare quotes.
